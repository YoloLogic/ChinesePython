一、这是一个【修改过的】CPython 3.14.7（重要）
----------------------------------------------

本发行包里的解释器是由**修改过的 CPython 源码**构建的，不是上游原版。
依据上游 PSF 许可的要求，我们在此明确声明：**我们改动了若干 CPython 源文件。**

改动内容（完整清单与联合哈希见开发仓 docs\构建基线.md，或运行 python --build-info）：

  * 词法/语法层新增**中文关键字拼写**（35 个硬关键字 + 3 个软关键字），英文拼写一律保留、行为不变
  * 新增**中文报错显示层**（CHINESEPYTHON_ERRORS = zh / en / both；str(e)、e.args 始终是英文）
  * 新增**词表驱动的中文标准库副本**（Lib\zh_*.py 与薄壳机制）；官方 Lib\** 的原文件未改动
  * 新增中文内置名 / 异常名 / 方法名的别名表与生成器

上游项目：https://github.com/python/cpython （基线 CPython 3.14.7）

四、包里装了哪些第三方（如实披露）
----------------------------------

本发行包**确实带了**上游 CPython 之外的第三方二进制组件：

  * tcl90.dll、tcl9tk90.dll —— **Tcl/Tk 9.0.4**（BSD 式许可，正文见 LICENSE-TCL-TK.txt）
  * libcrypto-3.dll、libssl-3.dll —— **OpenSSL 3**（Apache-2.0）
  * libffi-8.dll —— **libffi**；libtommath.dll —— **LibTomMath**（公有领域）
  * sqlite3.dll —— **SQLite**（公有领域）；zlib1.dll —— **zlib**
  * Lib\site-packages\pip —— **pip 26.2.1**（MIT，见其 METADATA 的 License-Expression: MIT）
  * vcruntime140.dll、vcruntime140_1.dll —— 微软**可再分发**的 Visual C++ 运行时库（app-local），
    按其再分发条款随包附带

各第三方许可**正文**：

  * LICENSE-第三方.txt —— 上游 Doc/license.rst 的**逐字节副本**（含 OpenSSL / expat / libffi /
    zlib / LibTomMath / SQLite 等；官方 HTML 版在包内 Doc\html\license.html）
  * LICENSE-TCL-TK.txt —— Tcl/Tk 的两份 license.terms 原文
